CAR RACING

Pista recta, tanque que se vacía y un auto con llamas. Llega a la meta antes de quedarte sin combustible.

Teclado: ←→ girar · ↑ acelerar · ↓ frenar · ENTER start · P pausaUsa los botones de abajo: ◀ ▶ para girar, GO para acelerar y START para empezar.

Cómo se juega

Cruza la línea de cuadros de cada ronda. El combustible baja con el tiempo y el juego termina si llega a cero. Recoge bidones naranjas para recargar. Cada ronda es más larga y más rápida.

Controles

  • ←→ o AD giran
  • ↑ o W acelera, ↓ o S frena
  • ENTER o ESPACIO es START
  • P o ESC pausa el juego
  • Botones ◀ y ▶ para girar
  • GO acelera. Al soltarlo el auto va bajando la velocidad
  • START empieza y continúa. Tocar la pantalla también sirve
  • El juego se pausa solo si cambias de pestaña

Qué hay en la pista

Paisajes y horario

Pradera, desierto, nieve y ciudad se van turnando cada kilómetro. Cada ronda tiene su hora: día, tarde con tinte naranja o noche, donde solo ves lo que alumbran los faros. El ciclo completo dura 8 rondas.
